# CivicPulse

A Smart Civic Complaint Management System built using Flask and Oracle Database.

---

## Features

- Citizen Registration
- Secure Login
- Complaint Registration
- Complaint Tracking
- Worker Assignment
- Department Management
- Complaint Priority
- Feedback System
- Analytics Dashboard

---

## Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- Oracle Database

---

## Project Structure

```text
app.py
config.py
templates/
static/
database/
services/
models/
routes/
```

---

## Run Project

Install dependencies

```bash
pip install -r requirements.txt
```

Run application

```bash
python app.py
```

Open browser

```
http://127.0.0.1:5000
```
